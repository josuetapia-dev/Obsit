# Obsit — Obsi-boty

Mascota de escritorio del equipo **Obsi** (UTGZ, proyecto integrador Gaya Calidad). Un robot 3D que vive en tu pantalla, se conecta a VS Code y a Claude Code, y te ayuda a entender y defender el proyecto `gaya-vainilla`: tour guiado, explicación de archivos, chat, preguntas de examen y retos.

| Carpeta | Qué hay |
|---|---|
| [`obsi-boty/`](obsi-boty/) | La app de escritorio (Electron + Three.js) y la extensión de VS Code. **Instrucciones en su README.** |
| [`prototipo/`](prototipo/) | El prototipo 3D en una sola página (para probar el diseño en el navegador). |
| [`referencias/`](referencias/) | Bocetos e imágenes de referencia del personaje. |

Equipo: Josué Pérez Tapia, Andrey Emilio Cabriales Ramírez, Ángel de Gabriel Aparicio Maldonado.
