# Obsi-boty para VS Code

Puente entre VS Code y Obsi-boty, la mascota de escritorio del equipo Obsi.

- Le avisa a Obsi-boty qué archivo tienes abierto y si VS Code está en primer plano.
- Comando **Obsi-boty: explicar este archivo** (`Ctrl+Alt+O`): pide la explicación sin tener que darle clic al robot.

Solo envía la ruta del archivo a `127.0.0.1:47321` (tu propia computadora). No manda nada a internet.
